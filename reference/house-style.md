# House Style — writing event copy for the Library

The governing reference is TRPL's own story guide. Where this file and the story guide
disagree, the story guide wins. What follows is what matters specifically for event listings.

## Voice

Write like a knowledgeable park ranger who is genuinely glad you came — not a professor
behind a podium. Plain, vivid, specific. Intellectually serious without being stuffy.

- **Lead with the story, not the institution.** T.R.'s life is inherently dramatic. Open with
  the thing that makes someone stop scrolling, then deliver the logistics.
- **Be concrete.** "A 90-minute walk through the gallery with the photographer who took the
  pictures" beats "a transformative visitor experience."
- **Avoid** vague aspirational language: *world-class*, *transformative journey*, *immersive
  experience*, *must-see*.
- **Minimal we/our/I/us.** Write about the event, not about ourselves.

## Hard rules

- **"Buttes," never "mesa."** (Exception: proper nouns like Mesa Verde.)
- **Present tense.** The Library is open. No pre-opening or future-tense copy.
- **Year-round** with seasonal hours — never frame the Library as summer-only.
- **"The Boardwalk,"** never "the Cultural Loop."
- **Advance-ticket and capacity messaging stays factual.** No overclaiming.

## T.R. quotes

**Verbatim or not at all.** Never paraphrase, modernize, or tidy a Roosevelt quote. If you
are not certain of the exact wording, describe the idea he expressed instead and flag it for
verification. A misquote on a presidential library's own channels is a real reputational problem.

Cite the source — speech, letter, book, date — whenever the format allows.

## Audience

Event copy has to work across a politically diverse national audience. Conservation,
leadership, civic duty, the strenuous life — these are shared values. Never position T.R.'s
legacy as belonging to one side. When a contemporary parallel suggests itself, ground it in
the shared value or leave it out.

## Accuracy — the rule that has already failed once

**Verify every age, date, count and number against the Library's own event page before
publishing, and re-verify when reusing copy from a previous cycle.**

A published Facebook description once said David Hume Kennerly became chief White House
photographer "at twenty-nine." He was **twenty-seven** — born 1947, appointed under Ford in
1974. He won the Pulitzer at twenty-five. The error sat on a post with 26 responses before
it was caught.

The lesson is not "be careful." It is: **numbers that can be checked with arithmetic should
be checked with arithmetic**, every time, including in copy you wrote yourself last month.

For anything beyond simple date math — a historical claim, a quote, an attribution — hand
off to the **historian-panel** plugin's `accuracy-review` skill rather than guessing.

## Links

Always link the event's **own page** on trlibrary.com, not the calendar index and not the
homepage. Platforms that offer a "ticket URL" or "learn more" field get that same link.

## Per-platform length limits

| Platform | Field | Limit |
|---|---|---|
| Facebook | Event name | 100 chars |
| Google Business Profile | Title | 58 chars |
| Google Business Profile | Description | 1,500 chars |
| ND Tourism | Description | 100 min, 5,000 max |

GBP's 58-character title is the tightest constraint — usually the first thing to break when
reusing a Facebook title.
